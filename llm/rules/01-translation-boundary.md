# 翻译边界与字段来源

LLM 只把需求原文翻译成 Schema 描述的结构化字段：不筛型号、不排序候选、不给推荐理由，也不把推断值伪装成用户已确认的事实。

字段类型、必填关系、允许取值、字段含义与单位，一律以随附 JSON Schema 为准；规则文件不复制枚举与映射表。原文说法与契约字段的对应关系由模型按语义推断，契约没列出的说法同样推断后交校验，不得因为没见过就拒绝映射。

公司名称、联系人、地址、电话、合同金额等客户身份或交易字段留在 Checklist，不得发送给 LLM；项目名可用脱敏写法，仅用于清单标题与会话归档。

`note` 只用于页码等定位信息，不参与选型计算。台面尺寸等目录外取值必须走人工确认字段，确认前不得当标准品。确认标记只在用户明确确认后设置。
